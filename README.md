
1. Project Title

Personal Portfolio Website — BELEDE RISHIKA

A modern, responsive, and professional portfolio website developed as an internship project to showcase academic background, technical skills, projects, achievements, and contact information.

Student: BELEDE RISHIKA
Branch: ECE — Electronics & Communication Engineering
College: MATRUSRI ENGINEERING COLLEGE

2. Project Description

This project is a responsive personal portfolio website created using front-end web technologies.

The website provides a professional online profile where a student can present:

Personal introduction
Educational background
Technical skills
Projects
Career interests
Contact information
Social/professional links

The design focuses on a clean, modern interface that works across desktop, tablet, and mobile devices.

5. File Description
index.html

This is the main webpage.

It contains the complete structure of the portfolio, including:

Navigation
    ↓
Hero Section
    ↓
About Section
    ↓
Skills Section
    ↓
Projects Section
    ↓
Education Section
    ↓
Contact Section
    ↓
Footer

The HTML uses semantic elements such as:

<header>
<nav>
<main>
<section>
<footer>

This improves the structure, accessibility, and readability of the website.

style.css

This file controls the complete appearance of the website.

It contains styling for:

Page layout
Navigation
Hero section
Buttons
Cards
Skills
Projects
Contact form
Responsive design
Animations
Mobile screens

Example:

body {
    margin: 0;
    font-family: "DM Sans", sans-serif;
    background: #0b0d0c;
    color: #ffffff;
}

The stylesheet also contains responsive rules so that the website adapts to different screen sizes.

script.js

This file adds interaction to the website.

For example, the mobile navigation can be controlled using JavaScript:

menuButton.addEventListener("click", () => {
    navigation.classList.toggle("active");
});

JavaScript is also used for scroll-based effects and form interaction.

assets/profile.svg

This is the profile image placeholder used in the portfolio.

It can be replaced with your actual professional photograph.

For example:

assets/profile.jpg

The image reference in index.html can then be updated accordingly.
